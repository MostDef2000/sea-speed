## Architecture

- worker_tracking.py: the pure-Python tracking cluster — 3 state literals + 8 defs in source order. Imports: time (sample timestamps) + worker_kernel (env_float, DETECTION_* tunables) + worker_transport (fetch_speed_config/fetch_speed_lines_config, calibration configs). NO cv2/numpy (the tracking math is pure Python over detection dicts), NO threading/queue (no thread/queue lifecycle — that is the wave-7 publisher), NO datetime/ultralytics/av/subprocess/socket/requests/json/pathlib/os.
- Object-identity coupling: `_speed_track` (dict literal), `_track_states` (empty dict) and `_line_speed_state` (dict literal) are defined ONCE in worker_tracking and re-exported BY IDENTITY; every access anywhere is an in-place mutation or a read of the same dicts (nothing rebinds them — AST-guarded across all worker sources). UNLIKE wave 7 there is NO rebinding name in the moved set (no `global` statement names any of the 11 moved names anywhere) — so no rebinder-coupling pin is needed; the strict no-rebinding guard covers all three state names.
- hls_motion_yolo_worker_events.py: keeps ROI family, draw_speed_lines_overlay, build_event, detect_vehicles, the live-envelope builders and main. Staying callers of the moved defs resolve via the fourth flat sibling re-export: `main` → update_speed_estimate/update_speed_lines_estimate/convert_px_s_to_kmh/prune_track_states/water_event_candidates/track_event_posted/mark_track_event_posted, `build_event` → convert_px_s_to_kmh. Import cycle safety: worker_tracking imports worker_kernel + worker_transport (never the worker — chain tracking→transport→media→kernel acyclic); the new re-export block sits after the wave-7 block, before first use.
- Gate scan model: MODULE_SOURCES extends to the SEVEN-file union (worker + media + render + transport + crossings + live + tracking); REQUIRED_ENV_NAMES unchanged — the moved region reads NO required env names (env audit) and the union scan keeps every required env read covered.

## Decisions

- D-1: Verbatim byte-level move (assertion-guarded script, ONE contiguous region 479-739) instead of retyping: guarantees byte- and AST-identity, verified programmatically after the write against `git show f9d4f37` (moved region AND all three staying regions byte-identical; 11/11 names AST-identical; moved names gone from worker; zero duplicate defs).
- D-2: A FOURTH ImportFrom (module worker_tracking) is allowed: the transport/crossings/live pins filter on their own `node.module` values, so the exactly-one assertions are per-module; the new block carries the 11 names sorted — defs AND state names, like wave 7: the state re-export preserves object identity (ONE state-dict set visible under both namespaces) and the monkeypatch/ns-injection surface.
- D-3: All three state names are strictly non-rebinding (AST-verified pre-write: the ONLY Store access across worker/*.py is the defining literal in worker_tracking.py — the moved bodies mutate in place), so the wave-7 rebinder-coupling class has NO analogue this wave: the strict no-rebinding guard + the global-statement guard (covering all 11 moved names) are the complete state contract.
- D-4: The recorded STAYS are forced, not stylistic: the ROI family stays because `_roi_processing_points` rebinds and its callees are cv2/numpy; `draw_speed_lines_overlay` stays because it is a render surface (cv2) with ZERO moved-name callers and no production callers — its placement is PINNED both directions (def present in the worker, absent from worker_tracking) so a later drift moves it only through a conscious contract change; `detect_vehicles`/`build_event`/`build_*_live_envelope`/`main` and MotionDetector stay (model/cv2/ultralytics domain + supervision loop).
- D-5: NO dead-import removal this wave (forced deviation from the wave-7 pattern): `time`/`env_float`/`fetch_speed_config`/`fetch_speed_lines_config` all keep staying users in the worker; the worker's import surface only GAINS the flat sibling re-export. Cut-tool artifact, recorded honestly: the extraction script prepended a UTF-8 BOM to line 1 of BOTH worker sources (inert — all repo readers use utf-8-sig); stripped in-branch by a follow-up commit before merge, so the final tree is byte-identical to origin/main f9d4f37 modulo the intended cut+re-export only.
- D-6: NO monkeypatch-target transfers and NO #398 pin edits this wave: the ns-injection fakes (tests/support harness pattern) are exec-based and location-independent — the harness resolves moved defs from worker_tracking (first-definition-wins across the EIGHT sources) and injected fakes replace bare names in the exec namespace. The env audit (zero required-env reads in the moved region) means the media-module union test needs no STAYS transfer — verified by the full battery; if it failed, STOP and report instead of editing the test.
- D-7: validate_sdd GRANDFATHERED_PREFIX_COLLISIONS "397" gains the wave-8 dir — the scheduled exact-set break continuing the 396/waves-1-7 pattern.
