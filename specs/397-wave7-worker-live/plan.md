## Architecture

- worker_live.py: the live-publisher thread/queue shim over the transport — 3 state literals + 3 defs in source order. Imports: queue/threading (the module OWNS the publish-thread lifecycle) + worker_kernel (env_str) + worker_transport (_post_live_envelope_sync). NO cv2/numpy/datetime, NO ultralytics/av, NO subprocess/socket, NO requests/json/pathlib/os.
- Thread-lifecycle ownership: `_LIVE_PUBLISH_QUEUE` (bounded, maxsize=1) and `_LIVE_PUBLISH_LOCK` are defined ONCE in worker_live and re-exported BY IDENTITY; every access anywhere is a method call on the same objects (nothing rebinds them — AST-guarded). `_LIVE_PUBLISH_THREAD` (module-level `None` literal) rebinds ONLY inside `_ensure_live_publisher` under `global` — the daemon thread is (re)created on the next publish if dead; the literal moved WITH its sole rebinder so the pair is never split.
- hls_motion_yolo_worker_events.py: keeps ROI family, speed-lines domain, track/event pipeline and main. Staying callers of the moved entry point resolve via the third flat sibling re-export: `main` → `post_live_envelope(env_live)` (road + water live envelope call sites). Import cycle safety: worker_live imports worker_kernel + worker_transport (never the worker — chain live→transport→media→kernel acyclic); the new re-export block sits after the crossings block, before first use.
- Gate scan model: MODULE_SOURCES extends to the SIX-file union (worker + media + render + transport + crossings + live); REQUIRED_ENV_NAMES unchanged — the family's env reads (SEA_SPEED_LIVE_API_URL/SEA_SPEED_API_URL/SEA_SPEED_API_TOKEN via env_str) are already required and resolved across the union; the union scan keeps every required env read covered.

## Decisions

- D-1: Verbatim byte-level move (assertion-guarded script, two contiguous regions 127-129 and 466-502) instead of retyping: guarantees byte- and AST-identity, verified programmatically after the write against `git show 20657e7` (both regions byte-identical; 6/6 names AST-identical; moved names gone from worker; zero duplicate defs).
- D-2: A THIRD ImportFrom (module worker_live) is allowed: the transport/crossings pins filter on their own `node.module` values, so the exactly-one assertions are per-module; the new block carries the 6 names sorted — defs AND state names, unlike wave 6: the state re-export preserves object identity (ONE queue/lock/thread visible under both namespaces) and the monkeypatch/ns-injection surface.
- D-3: `_LIVE_PUBLISH_THREAD` moves WITH its sole rebinder `_ensure_live_publisher` (never split): a rebinding name cannot move away from its rebinder without changing semantics; the AST no-rebinding guard covers the other 2 state names, the global-statement guard covers the defs, and the rebinder-coupling pin (test (d)) freezes the pairing (exactly one Assign beyond the literal; enclosing FunctionDef; sole ast.Global; both top-level in worker_live).
- D-4: The recorded STAYS are forced, not stylistic: the ROI family stays because `_roi_processing_points` rebinds and its callees are cv2/numpy; `_line_speed_state` + `update_speed_lines_estimate` stay (speed-lines analytics domain, sole consumer); `detect_vehicles`/`main` and the track/event pipeline stay (model/cv2 domain + supervision loop).
- D-5: Two dead `import queue`/`import threading` lines are removed from the worker as part of the cut (forced deviation): the sole uses (state literals + defs, pre-cut :3-4/:127-129/:466-502) all moved; grep + AST sweep confirm zero remaining `queue`/`threading` references in the worker; ruff F401 would fail CI otherwise; the gate's union scan does not pin queue/threading in the worker file.
- D-6: NO monkeypatch-target transfers and NO #398 pin edits this wave: the ns-injection fakes (tests/support harness pattern) are exec-based and location-independent — the harness resolves moved defs from worker_live (first-definition-wins across the SEVEN sources) and injected fakes replace bare names in the exec namespace.
- D-7: validate_sdd GRANDFATHERED_PREFIX_COLLISIONS "397" gains the wave-7 dir — the scheduled exact-set break continuing the 396/waves-1-6 pattern.
- D-8: The transport gate test class name `CompatibilityGateFourFileTests`/`test_gate_scans_four_worker_sources` (stale since wave 5) is renamed to the count-neutral `CompatibilityGateModuleSourcesTests`/`test_gate_scans_module_sources` in the same commit as the wave-7 gate-count transfer — the wave touches those exact lines anyway, and the rename removes the recurring stale-name hygiene debt (recorded as a wave-6 KB candidate) without any semantic change.
