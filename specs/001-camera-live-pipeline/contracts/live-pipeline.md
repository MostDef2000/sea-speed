# Camera Live Pipeline Contract

Status: Accepted
Specification: specs/001-camera-live-pipeline/spec.md

## Normative requirements

1. A camera's public identity MUST remain stable across source or codec changes unless the product specification explicitly changes it.
2. Live viewing MUST be independent of AI processing availability.
3. The system MUST prepare a broadly browser-compatible stream when the camera's native media is not broadly browser-compatible.
4. The browser MUST NOT be required to consume the camera's native codec directly.
5. VPS MediaMTX MUST NOT be treated as a mandatory Camera 1 browser-path dependency.
6. Camera credentials MUST NOT be embedded in public browser URLs or committed repository content.
7. Future camera onboarding SHOULD require only a camera identity plus protected source/relay configuration, with compatibility output generated by the system.
